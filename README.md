# Salah Qaraeen — Portfolio Website

Personal portfolio site showcasing my background, skills, and projects as a Full Stack / Backend Developer.

## Overview

Single-page portfolio built with plain HTML, CSS, and JavaScript.

- **About** — background and education
- **Skills** — languages, frameworks, databases & tools
- **Projects** — filterable by Frontend / Backend / Full Stack
- **Experience** — training and work history
- **Contact** — contact info and a message form
- **Resume viewer** — CV opens as an embedded PDF in a modal

## Project Structure

```
portfolio/
├── assets/
│   ├── icons/
│   ├── selfie.jpeg
│   └── Salah_Qaraeen_CV.pdf
└── src/
    ├── index.html
    ├── index.css
    └── index.js
```

## Running Locally

Open `src/index.html` with VS Code's **Live Server** extension (right-click → "Open with Live Server").

Don't open the file directly by double-clicking it — the resume PDF won't load under `file://` due to browser security restrictions.
